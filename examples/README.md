# Example: quantile plots from a synthetic Navigate report

This example runs Lantern on a small synthetic dataset shaped like a
combined Navigate report: two scenarios ("ambitious" and "conservative"),
20 samples each, 2025-2050, with two single metrics (`TotalEquivalentWTW`,
`Expenses`) and one multi-metric (`ConsumedEnergy` split into fuel oil,
methanol, and ammonia).

## Run it

```bash
cd examples
lantern report.csv --config lantern.toml --outdir output
```

This writes to `output/`:

- `emissions.html`, `expenses.html` — combined quantile plots (p5/p50/p95
  bands per scenario, representative pathway overlaid)
- `consumed_energy_grid.html` — subplot grid, one panel per fuel
- `ambitious/`, `conservative/` — the same plots per scenario
- `percentiles.csv` — tidy long table of the quantiles
- `representatives.csv` — the chosen representative sample per scenario, in
  the original CSV layout

Other things to try:

```bash
lantern report.csv --list-scenarios            # what's in the CSV?
lantern report.csv --config lantern.toml --validate
lantern report.csv --config lantern.toml --mode traces --outdir output
```

## The files

- `report.csv` — the synthetic input, generated by `make_report.py`
  (deterministic, seed 42). Regenerate it with `python make_report.py`.
- `lantern.toml` — a minimal config for this dataset, with comments. The
  full configuration reference is in
  [`docs/user-manual.md`](../docs/user-manual.md).

## Using your own data

Point Lantern at a combined Navigate report CSV and let it draft the
config for you:

```bash
lantern your_report.csv --init        # writes a starter lantern.toml
lantern your_report.csv --validate    # checks the config against the CSV
```
